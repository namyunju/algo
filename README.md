# Algorithm Solutions

알고리즘 문제 풀이 저장소입니다.

## 구성

문제는 `사이트 → 난이도 → 문제번호-문제명` 순서로 정리합니다. 사용한 언어는 문제 폴더 안의 파일 확장자로 구분합니다.

```text
programmers/
└─ 2/
   └─ 42586-기능개발/
      ├─ solution.py
      └─ README.md

swea/
└─ D4/
   └─ 1249-보급로/
      ├─ solution.py
      └─ README.md
```

## 풀이 목록

| 사이트 | 문제 수 |
|---|---:|
| Programmers | 풀이 폴더에서 확인 |
| SWEA | 풀이 폴더에서 확인 |

문제별 README에는 풀이 아이디어, 시간 복잡도, 사용 알고리즘, 다시 풀기 여부를 기록합니다.
