'''
5000개 버정
노선은 N개 

i번째 노선은 번호가 Ai 이상 Bi 이하인 정류장만을 다님

P개의 정류장 번호가 주어질 때 해당 번호의 정류장을 지나는 노선의 가짓수


3번 노선은 A3 이상 B3 이하 번호의 정류장을 지남.

x번 정류장을 지나는 노선의 총 개수는 어떻게 구할 수 있을까
노선은 최대 500개밖에 없음.

노선의 시작점과 끝점
'''

T = int(input())
for tc in range(1, T+1):
    N = int(input())
    busmap = []
    for _ in range(N):
        a, b = map(int, input().split())
        busmap.append((a, b))

    busmap.sort()
    P = int(input())
    ans = []
    for _ in range(P):
        cnt = 0
        c = int(input())
        for i in range(N):
            if busmap[i][0] > c:
                break
            if busmap[i][0] <= c <= busmap[i][1]:
                cnt += 1
        ans.append(cnt)
        
    print(f'#{tc} ', end='')
    print(*ans)
